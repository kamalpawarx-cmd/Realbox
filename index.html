Add-ons

Add catalogs by link, pasted JSON or file, much like CloudStream repositories.

Add-ons are just catalogs.

A catalog is a short JSON file that lists titles and links to video files. Paste one in, add it by link or import the file, and its titles show up on Home.

Reelbox comes with one add-on of free Blender open movies. It does not include or endorse any streaming site. Add only catalogs you have the right to use.

{
  "name": "My Collection",
  "items": [
    {
      "title": "Sample Movie",
      "type": "movie",
      "url": "https://example.com/movie.mp4"
    },
    {
      "title": "Sample Series",
      "type": "series",
      "episodes": [
        { "title": "Pilot", "url": "https://example.com/e1.mp4" },
        { "title": "Episode 2", "url": "https://example.com/e2.m3u8" }
      ]
    }
  ]
}

Get Reelbox in three steps.

1

Download the file

Tap Download Reelbox. You get a single file named reelbox.html.

2

Open it in your browser

Find it in Downloads and open it with Chrome, Safari or any modern browser.

3

Add it to your home screen

Use the browser menu and choose Add to Home Screen. Reelbox then opens like an app.

Download Reelbox Prefer not to download? Choose Open web app at the top and add that page to your home screen.

Questions

Where are my videos stored?

On your device, inside your browser's storage. Nothing you add is uploaded to a server.

Does it come with movie sites?

No. Reelbox ships with one add-on of free open movies. Everything else is a catalog you choose to add.

What if a video won't play?

The link must point to an mp4, webm or HLS stream, and the host must allow other sites to load it.
